## 보안 처리

- API 키가 보이는 이미지는 포함하지 않았습니다.
- 이메일 주소가 표시된 Git 설정 화면은 제외했습니다.
- Vercel 기기 로그인 인증 코드가 표시된 화면은 제외했습니다.
- 중복 화면과 최종 성공을 증명하지 못하는 중간 실패 화면은 제외했습니다.

## 권장 제출 구성

과제의 기본 증빙에는 `01`부터 `06b`까지를 사용하고, `07`부터 `10`까지는 정상 입력·모바일 폼·재추천·서버 상태를 보강하는 자료로 사용합니다.
