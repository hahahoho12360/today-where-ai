# 서비스 기획서 - 오늘 어디로?

## 1. 서비스 목적

여행지를 멀리서만 찾지 않고, 현재 위치나 전국의 동네 한 곳을 기준으로 실제 생활에 쓸 수 있는 하루 일정을 빠르게 만든다. 기존 Python CLI 여행 추천 결과를 웹의 입력 폼, 카드, 저장 기능으로 바꾼다.

## 2. 타깃 사용자

- 주말 계획을 짧은 시간에 세우고 싶은 사람
- 아이·가족·친구·연인과 동네 나들이를 원하는 사람
- 음식점뿐 아니라 카페와 주차장을 한 번에 확인하고 싶은 사람
- 모바일에서 바로 열어 볼 간단한 일정표가 필요한 사람

## 3. 페이지·섹션 구조

| 섹션 | 사용자 행동 | 결과 |
| --- | --- | --- |
| 1. 지역 선택 | 직접 입력 / 현재 위치 / AI 후보 중 선택 | 법정동과 행정동이 확인된 지역 |
| 2. AI 일정 | 날짜·동행·교통·관심사·예산 입력 | 실제 장소 ID가 붙은 시간표 |
| 3. 생활 장소 | 추천 확인, 개별 또는 전체 재추천 | 음식점·카페·주차장 각 1곳 |
| 4. 날씨·행사 | 생성 결과 확인 | 예보와 실제 행사, 또는 정직한 미제공 안내 |
| 5. 내 여행 | 복사·다운로드·인쇄·최근 결과 열기 | 재사용 가능한 개인 여행 요약 |

## 4. 핵심 AI 기능

### 기능 A: 전국 동네 후보 추천

- 입력: 날짜, 출발지(선택), 동행, 교통, 관심사, 예산
- 처리: AI가 내부적으로 후보 5곳을 만들고 카카오 주소 API가 실제 주소인지 확인
- 출력: 검증에 성공한 법정동·행정동 2~3곳과 추천 이유
- 사용자 가치: 지역을 모르는 사람도 시작할 수 있음

### 기능 B: 검증 장소 기반 일정 생성

- 입력: 확인된 지역, 날짜, 시간, 동행, 교통, 관심사, 예산, 검색 반경
- 처리: 카카오가 장소 후보를 제공하고 AI는 후보 ID 안에서만 선택·배열
- 출력: 시간표, 음식점·카페·주차장, 날씨 팁, 준비물
- 사용자 가치: AI의 설명 능력과 검색 API의 사실성을 함께 사용

## 5. 실패 처리 기준

| 실패 | HTTP/브라우저 상황 | 사용자 안내와 다음 행동 |
| --- | --- | --- |
| 빈 지역 | 입력 누락 | 전체 지역명을 입력하도록 안내하고 입력창에 초점 |
| 모호한 동 | 422 | 시·도부터 동까지 입력하도록 예시 제공 |
| 위치 권한 거부 | 브라우저 오류 1 | 직접 입력으로 전환 안내 |
| 현재 위치 오차 큼 | 정확도 1km 초과 | 표시 지역 확인 또는 직접 입력 권고 |
| API 키 누락 | 503 | Vercel 환경 변수 확인 안내 |
| 인증 실패 | 401/403을 503으로 정리 | 키와 권한 확인 안내 |
| 사용량 초과 | 429 | 잠시 후 재시도 안내 |
| 네트워크·외부 API 실패 | 502 | 인터넷·외부 서비스 상태 확인 안내 |
| 타임아웃 | 서버 504 또는 브라우저 26초 | 잠시 후 재시도 안내 |
| 장소 없음 | 404 | 반경 3km → 5/10km 확대 안내 |
| 행사 없음 | 정상 빈 결과 | “확인된 행사가 없음” 표시, 가짜 행사 생성 금지 |

## 6. 데이터와 개인정보

- API 키는 Python 서버의 환경 변수에서만 읽는다.
- 현재 위치는 사용자가 버튼을 누를 때만 요청한다.
- 정확한 위도·경도는 localStorage의 최근 여행에 저장하지 않는다.
- 외부 응답 원문과 키를 사용자 오류 메시지 또는 화면에 노출하지 않는다.
- 장소명·주소·링크는 검색 API에서 얻고, AI는 선택과 설명만 한다.

## 7. 성공 기준

- 데스크톱과 390px 모바일에서 가로 스크롤 없이 사용 가능
- 메뉴 5개가 각 섹션으로 이동
- 정상 입력에서 AI 결과가 화면에 표시
- 빈 입력, API 오류, 타임아웃 중 최소 1개 이상을 사용자 문장으로 표시
- 음식점·카페·주차장 각각 한 곳 표시 또는 실제 결과가 없다는 정직한 안내
- 새로고침 뒤 최근 여행 5개가 유지
- 공개 배포 URL을 동료가 로그인 없이 테스트 가능
